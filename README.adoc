== Documentation

The whole public and private documentation of the Jengu project is written in {asciidoc} and published using {antora} documentation site generator.

The documentation site is organized by {antora} and starts from ./antora-playbook.xml.
The project contains set of antora modules under ./documentation/ which are describing overall project architecture plus each gradle subproject may contain its own specific set of {antora} modules (see description below).

Only one site will be built by running `./gradlew antora` from the root project root.
